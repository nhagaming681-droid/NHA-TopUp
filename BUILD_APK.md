# NHA TopUp — Cloud APK Build

This project includes a GitHub Actions workflow that builds the Android APK in the cloud.

1. Upload the complete project to a GitHub repository.
2. Push to the `main` branch, or run the workflow manually from Actions.
3. Wait for the workflow to finish.
4. Download the `NHA-TopUp-APK` artifact.

This starter app is a demo/store UI. It does not yet deliver real MLBB Diamonds or PUBG UC. Real delivery requires an authorized supplier/API, secure backend, and payment integration.
